# MasuDone!

ToDoリストを **ビンゴカード** にして、終わったマスに **スタンプ** を押していく、かわいいモンスターたちと一緒に使うタスク管理アプリです。

3×3 または 5×5 のマスひとつひとつが ToDo になっていて、縦・横・斜めがそろうと「BINGO!」。全部そろうと、みんなでお祝いしてくれます。

## 使ってみる

**Web版(ブラウザで開くだけ・登録不要・無料)**

**https://mizuno-yuka.github.io/masudone/**

- パソコンでもスマホでも使えます(Chrome・Edge・Safari・Firefox の最新版)
- 一度開けば、ネットがなくても使えます(オフライン対応)
- ブラウザの「インストール」や「ホーム画面に追加」で、アプリのように使えます

**Windows用インストーラー(.exe)**

作り方は、下の「開発者向け」にあります。インストーラーを配布するときは、公開ページ(GitHub の Releases)に置きます。

## できること

- 3×3 / 5×5 のボードを、名前をつけて何枚でも作れる
- マスに、タイトル・締切日・メモを書ける(締切が近い・過ぎたマスは、控えめに色が変わります)
- 終わったマスにスタンプ(モンスターが「DONE!」と顔を出します)。押し間違えても取り消せる
- 書き込んだマスは、**ドラッグして別のマスへ移せます**(空のマスへ移動、中身があるマスとは入れ替え)。スマホやタブレットでは、マスを**長押し**してから動かします。**スタンプを押したマスは動かせません**(動かしたいときは、スタンプを取り消します)
- ビンゴ判定・ライン強調・「N BINGO!」の表示・お祝いのアニメーション、全マス制覇の特別演出
- すべて完了したボードや、アーカイブしたボードは「履歴」に残る(閲覧専用)
- 変更は自動で保存される
- データのバックアップ(書き出し/読み込み)ができる(「履歴」画面の下にあります)

## データとプライバシー

- アカウント登録はありません。**入力した内容は、サーバーには送られません。**
- **Web版**では、いま使っているブラウザの中にだけ保存されます。ブラウザの「閲覧データの削除」をすると消えます。別のブラウザや別の端末には引き継がれません。
- 大事なデータは、「履歴」画面の「書き出す」で、ファイルに保存しておくと安心です。別の端末に移すときは、「読み込む」を使います。
- **インストーラー版**では、このパソコンの中のファイルにだけ保存されます。

# 開発者向け(自分でビルドしたいとき)

以下は、プログラムの動かし方・インストーラーの作り方・Web版の公開のしかたです。

## 1. はじめに必要なもの(最初の1回だけ)

**Node.js** というソフトが必要です(アプリを動かす土台のようなものです)。

1. https://nodejs.org/ja を開く
2. 「LTS」と書かれた緑のボタンでダウンロードして、インストーラーを開く
3. 画面の指示どおり「次へ」を押していけばOK(設定はそのままで大丈夫です)
4. インストール後、**パソコンを再起動**(またはターミナルを一度閉じて開き直す)

> すでにインストール済みか確認したいとき:ターミナルで `node -v` と打って、`v○○.○○.○` と出ればOKです。

## 2. ターミナルを開く(この MasuDone フォルダで)

1. エクスプローラーで、この `MasuDone` フォルダを開く
2. 上のアドレスバー(フォルダの場所が書いてあるところ)をクリックする
3. `powershell` と入力して Enter
4. 青(または黒)い画面が開けば成功です

## 3. 部品をインストールする(最初の1回だけ)

ターミナルに次を貼り付けて Enter を押します。数分かかります(約100MBのダウンロード)。

```bash
npm install
```

終わると「added ○ packages」のような文字が出ます。
「npm warn …」の黄色っぽい警告が出ても、気にしなくて大丈夫です。

## 4. アプリを起動する

```bash
npm start
```

ウィンドウが開いたら成功です。

## 5. 使い方(ステップ1)

- 右上の **「＋ 新しいボード」** で、名前と大きさ(3×3 / 5×5)を決めてボードを作る
- マスをクリック → ToDoを書いて「保存」
- 「スタンプを押す」で完了(ポンッとスタンプが押されます)、もう一度開いて「スタンプを取り消す」で元に戻せます
- 何も書いていないマスにはスタンプを押せません
- 右上のプルダウンでボードを切り替えられます
- 変更は **自動で保存** されます。保存ボタンはありません

### ビンゴ(ステップ2)

- 縦・横・斜めのどれかのラインが全部スタンプで埋まると **ビンゴ!** になり、紙吹雪と「N BINGO!」の演出が出ます
- 揃ったマスは黄色く光り続け、ボード名の横に「N BINGO!」と揃ったライン数が出ます
- スタンプを取り消してラインが崩れると、光とライン数も元に戻ります(取り消したときは演出は出ません)
- **全マス制覇**すると、さらに豪華な「COMPLETE!」演出が出ます
- アプリを開き直したときや、ボードを切り替えたときには演出は出ません(スタンプを押した瞬間だけ)

### 複数ボード・履歴・締切・メモ(ステップ3)

- **ボードの切り替え**:右上のプルダウンで進行中のボードを選べます
- **名前を変更 / アーカイブ / 削除**:ボードの下のボタンから。削除は元に戻せません(確認が出ます)。残したいときは「アーカイブ」を使ってください
- **履歴**:右上の「履歴」ボタンで開きます。次の2種類が並びます
  - **アーカイブしたボード**:閲覧専用です(マスをクリックしても内容を見るだけ)。「進行中に戻す」でいつでも戻せます
  - **全マス完了したボード**:自動で履歴にも載ります(進行中のボードとしても残るので、スタンプの押し間違いを直せます。不要になったらアーカイブしてください)
- **締切日**:マスの下に小さく表示されます。2日以内は黄色、期限切れは赤で、左上に小さな三角の目印が付きます(完了したマスは警告しません)
- **メモ**:メモのあるマスは右上に ✎ マークが付きます。マスにマウスを乗せると、タイトル・締切・メモの全文が出ます。マスをクリックすれば編集画面で読めます

## 5.5 インストーラー(.exe)をつくる

「`npm start` を打たなくても、ダブルクリックで起動できる形」にする手順です。手順3まで終わっていれば、すぐできます。

1. ターミナルで次を実行します(1〜3分かかります。途中でいくつか部品が自動ダウンロードされます)

```bash
npm run build
```

2. 終わると、フォルダの中に `dist` というフォルダができ、この中に **`MasuDone-Setup-1.0.0.exe`**(約80MB)ができます
3. このファイルをダブルクリックすると、インストールが始まります
   - インストール先を選べます(そのままでOK)
   - デスクトップとスタートメニューに「MasuDone!」のショートカットができます
4. 以後は、ショートカットのダブルクリックで起動できます

### 起動時に「WindowsによってPCが保護されました」と出たら
このインストーラーには「発行元の署名」(有料の証明書)が付いていないため、Windowsが念のため警告を出します。自分で作ったアプリなので、次の操作で進めて大丈夫です。

1. 警告画面の **「詳細情報」** をクリック
2. 出てきた **「実行」** をクリック

### 補足
- **アンインストール**:Windowsの「設定 → アプリ → インストールされているアプリ」から「MasuDone」を削除します。**ボードのデータ(下の保存場所)は消えません**
- **データの引っ越し**:別のPCに移したいときは、`data.json` をコピーして同じ場所に置きます
- **バージョンを上げて作り直す**:`package.json` の `"version": "1.0.0"` を書き換えてから `npm run build`
- `dist` フォルダは大きい(数百MB)ので、OneDrive の同期が重くなることがあります。ビルドが終わったら、`MasuDone-Setup-1.0.0.exe` だけ別の場所にコピーして、`dist` フォルダは削除しても大丈夫です(また `npm run build` で作れます)
- アイコンを変えたいときは `build/icon.png` を差し替えます(`build/icon.ico` も一緒に作り直しが必要なので、そのときは相談してください)

## 5.8 画像素材について

- アプリに出てくるモンスター6体(`src/img/mon-*.png`)と、アプリのアイコン(`build/icon.png` `build/icon.ico` `src/icon-192.png` `src/icon-512.png`)は、作者(MIZUNO Yuka)が ChatGPT を使って作成した画像です。
- 画像を差し替えたいときは、`src/img/` の6つの画像(`mon-blue` `mon-yellow` `mon-teal` `mon-red` `mon-purple` `mon-green`)を、同じ名前のPNG(背景が透明なもの)に入れ替えます。

## 5.9 Web版を公開する手順(GitHub Pages)

Web版は、`docs` フォルダの中身を、そのままインターネットに置くだけで動きます(サーバーのプログラムは要りません)。

### 公開用の `docs` フォルダを作り直すとき
プログラム(`src` の中身)を変えたら、ターミナルで次を実行します。`docs` フォルダが作り直されます。

```bash
npm run build:web
```

さらに、**変更を公開したあとにオフライン用の記憶を入れ替える**ために、`src/sw.js` の中の `const VERSION = 'v1';` の数字を `v2`, `v3` …と上げてから実行してください(上げ忘れると、前に開いた人の画面に、古い版が残ることがあります)。

### 変更を公開サイトに反映するとき(2回目以降・いちばんよく使う手順)

この `MasuDone` フォルダ(`C:\MasuDone`)が、そのまま GitHub のリポジトリになっています。

1. `src` の中のプログラムを変更します(ふだんは、Claude に頼んで変更してもらいます)
2. `src/sw.js` の `const VERSION = 'v2';` の数字を、1つ上げます(`v3` など)
3. ターミナルで、公開用フォルダを作り直します

```bash
npm run build:web
```

4. GitHub Desktop を開き、「Changes」に出ている変更を確認して、「Summary」に内容を書き、「Commit to main」を押します
5. 上の「Push origin」を押します
6. 1〜2分ほどで、公開サイトに反映されます(反映されないときは、ページを2回、再読み込みしてください)

インストーラー(.exe)は、公開サイトとは別なので、必要なときに `npm run build` で作り直します(`dist` フォルダは GitHub には載りません)。

### 初めて公開するとき(GitHub Desktop を使う方法)

1. **GitHub Desktop** をインストールして、GitHub のアカウントでサインインします(https://desktop.github.com/)
2. **OneDrive の外**に、公開用のフォルダを作ります(OneDrive と Git は相性が良くないため)。たとえば `C:\Users\<ユーザー名>\Documents\masudone` を作って、この `MasuDone` フォルダの中身から、次のものだけをコピーします
   - `docs` / `src` / `build` / `scripts` フォルダ
   - `package.json` / `package-lock.json` / `README.md` / `LICENSE` / `.gitignore`
   - (`node_modules` と `dist` は、大きいのでコピーしません)
3. GitHub Desktop で「File → Add local repository」を選び、2 のフォルダを指定します。「リポジトリではありません」と出たら、「create a repository」をクリックして作ります(名前は `masudone` など)
4. 左下の「Summary」に「最初の公開」などと書いて、「Commit to main」を押します
5. 上の「Publish repository」を押します。**「Keep this code private」のチェックを外して**(= 公開リポジトリにして)、「Publish repository」を押します
6. ブラウザで GitHub の自分の `masudone` リポジトリのページを開きます
7. 「Settings → Pages」を開き、「Build and deployment」の「Source」を **Deploy from a branch** にして、「Branch」を **main**、フォルダを **/docs** にして「Save」を押します
8. 1〜2分待つと、同じページの上のほうに公開URLが出ます(`https://<ユーザー名>.github.io/masudone/`)。そのURLを開いて、動くことを確認します
9. このURLは、この README の「使ってみる」の部分に、すでに書いてあります(ユーザー名やリポジトリ名を変えたときは、書き直してください)

## 6. データの保存場所

ボードやスタンプのデータは、このPCの次の場所に保存されます(ネットには送られません)。

```
C:\Users\<ユーザー名>\AppData\Roaming\MasuDone\data.json
```

バックアップしたいときは、このファイルをコピーしておけばOKです。

> **旧名「ToDoBingo!」からの引き継ぎ**:以前の保存場所(`AppData\Roaming\ToDoBingo\data.json`)にデータがあれば、MasuDone! を初めて起動したときに自動でコピーされます。元のファイルは消しません。

## 7. フォルダの中身(参考)

| ファイル | 役割 |
|---|---|
| `package.json` | アプリの設定・必要な部品の一覧 |
| `src/main.js` | ウィンドウを開く・データをファイルに保存する |
| `src/index.html` | 画面の骨組み |
| `src/style.css` | 見た目(色・形・アニメーション) |
| `src/store.js` | データの保存先を切り替える(Web版=ブラウザ内、インストーラー版=PC内のファイル) |
| `src/sw.js` / `src/manifest.webmanifest` | Web版のオフライン対応と、ホーム画面に追加するための設定 |
| `docs/` | Web版の公開用フォルダ(`npm run build:web` で自動で作られます) |
| `scripts/` | Web版の公開用フォルダを作るプログラム |
| `src/app.js` | ボードやスタンプ、ビンゴ判定の動き |
| `src/celebrate.js` | 紙吹雪やバナーなどのお祝い演出 |
| `src/img/` | 背景・スタンプ・お祝いに登場するモンスターの画像(6体。ゆうさんが用意した画像から切り抜いたもの) |
| `src/fonts/` | 同梱しているフォント「LINE Seed JP」(SIL Open Font License。ライセンス文は `LICENSE-OFL.txt`) |
| `build/` | アイコンと、インストーラー作成用の設定 |
| `dist/` | `npm run build` で作られるインストーラーの置き場(自動で作られます) |
